# Unity integration — play npcforge output in a scene

Drop-in Unity 2022 starter that runs npcforge-generated Yarn dialogue with
Yarn Spinner 2. After the 5-minute setup in [`SETUP.md`](SETUP.md) you have
a scene where Mira greets you differently in the morning vs. at night, and
remembers you across visits.

## What's in the box

```
unity_integration/
├── README.md                     this file
├── SETUP.md                      step-by-step Unity setup
└── Assets/NpcForge/              drop this folder into your Unity Assets/
    ├── README.md                 folder-level explainer
    ├── Scripts/
    │   ├── NpcForgeDialogueController.cs
    │   ├── TimeOfDayController.cs
    │   ├── NpcApproachButton.cs
    │   └── NpcForgeStartup.cs
    └── Dialogue/
        ├── world.yarn                              Start + <<declare>> defaults
        ├── mira_vesser.yarn                        walk-up, 9 intent branches
        ├── mira_vesser_greet_time_of_day.yarn      5 time-of-day variants
        └── mira_vesser_repeat_greet.yarn           4 visit-gated variants
```

All four `.yarn` files were generated by npcforge and are ready for Yarn
Spinner 2 to compile. No post-processing required.

## What you'll see running

1. **Time-of-day UI buttons** → click "Morning" / "Night" / ... to set
   `$time_of_day`.
2. **"Approach Mira" button** → plays `mira_vesser_Greet_time_of_day`,
   which branches on `$time_of_day` and shows the right greeting.
3. **Second click** on Approach → Yarn's `visited_count()` ticks up →
   different greeting if you wired it to `mira_vesser_RepeatGreet`.
4. **"Full dialogue" button** → plays the walk-up tree with all 9
   intent options.

## Why this proves out the tool

Three things that are easy to claim and hard to demo:

- **State-aware output compiles** — the generated `.yarn` files import
  into Yarn Spinner without edits. No glue code in the dialogue itself.
- **State flows both ways** — C# reads `$disposition_mira`, Yarn reads
  `$time_of_day`, and the same `VariableStorage` is shared between them.
- **Visit tracking is free** — `visited_count()` is a Yarn Spinner
  built-in. The generator emits it; Unity honours it. No counter code
  required on the C# side.

## Regenerate your own

The files in `Dialogue/` are a snapshot. To regenerate against a modified
world bible or edited NPC sheets, run (from the repo root):

```bash
npcforge build           --demo-dir examples/rusted_lantern --mode walk_up
npcforge gen greetings   --demo-dir examples/rusted_lantern --only-npcs mira_vesser
npcforge gen repeat-greeting --demo-dir examples/rusted_lantern --only-npcs mira_vesser --n 4
```

Then copy the new `.yarn` files from `examples/rusted_lantern/out/` into
`unity_integration/Assets/NpcForge/Dialogue/`, overwriting the snapshot.
Yarn Spinner will reimport them automatically on the next Editor refresh.
